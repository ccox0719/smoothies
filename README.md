# Blend Lab Smoothie Calculator

A mobile-friendly Vitamix smoothie calculator with 30 recipes, protein variants, serving-size scaling, nutrition estimates, filtering, favorites, and recipe-specific generated artwork.

## Features
- 30 smoothie recipes
- Protein, breakfast, kid-favorite, berry, tropical, chocolate, green, and treat filters
- Search by recipe or ingredient
- Scale recipes from 1 to 12 servings
- Optional protein boost for non-protein recipes
- Estimated calories and protein
- Recipe-specific generated logo artwork
- Favorites stored in the browser when local storage is available
- Single-file static app with no build step

## Run
Open `index.html` directly, or deploy the repository with GitHub Pages / Netlify.

## GitHub Pages
In repository Settings → Pages, choose **Deploy from a branch**, then select **main** and **/(root)**.
